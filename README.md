### What I work on

- Canvas and model-driven apps on Dataverse, with Power Fx patterns that hold up at scale
- Power Automate flows and Azure integrations around them
- ALM for Power Platform: source control, the `pac` CLI and deployment pipelines
- VS Code extensions and AI-assisted tooling that make makers faster

### Projects

- **[Fusion Studio](https://github.com/devladlog/Fusion-Studio)**: Power Apps Studio inside VS Code.
  It adds a Git-first workflow for canvas apps, Power Fx AST analysis, dependency graphs, lint rules,
  Dataverse integration and AI-assisted screen generation.
  Install it from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=VladimiroLuis.powerapps-fusion-studio).

- **[Power Apps Manual](https://github.com/devladlog/powerapps-manual)**: a long-form guide to building,
  securing, governing and operating Power Apps. It covers canvas, model-driven, Power Pages,
  Dataverse and ALM, and includes a UX pattern library with 200+ Power Fx samples.
